## Full Run Example – User Flow

![Registration Screen](images/task5_readme/registration_run.png)  
**Step 1:** Register a new user.

![Login Screen](images/task5_readme/login_run.png)  
**Step 2:** Log in with the new account.

![Home Page](images/task5_readme/home_page_run.png)  
**Step 3:** Arrive at Home page.

![Side Menu](images/task5_readme/side_menu_run.png)  
**Step 4:** Open the side menu and create a new folder called "new folder".

![My Drive Page](images/task5_readme/my_drive_page_run.png)  
**Step 5:** Enter "new folder" and create a new file named "New file".

![Edit File Form](images/task5_readme/edit_file_run.jpg)  
**Step 6:** Edit "New file" content and save the changes.

![Picture Form](images/task5_readme/picture_run.jpg)  
**Step 7:** Create a new image file inside "new folder".

![Edit Picture Form](images/task5_readme/edit_picture_run.jpg)  
**Step 8:** Edit the image (replace or update the picture).

![Item Options Menu](images/task5_readme/item_options_menu_run.png)  
**Step 9:** Rename "New file" to "new name file", star it, and share it with another user.

![Starred Page](images/task5_readme/starred_run.png)  
**Step 10:** Open Starred page to verify the file appears as starred.

![My Drive Page](images/task5_readme/my_drive_page.png)  
**Step 11:** Delete "new name file" (moves to Bin).

![Bin Page](images/task5_readme/bin_page.png)  
**Step 12:** Open Bin and restore "new name file".

![My Drive Page](images/task5_readme/my_drive_page.png)  
**Step 13:** Delete "new name file" permanently.

![Settings Menu](images/task5_readme/settings_menu.png)  
**Step 14:** Open settings, toggle dark mode, and change language.

![Recent Page](images/task5_readme/recent_page.png)  
**Step 15:** Check Recent page to see activity history.

![Shared Page](images/task5_readme/shared_page.png)  
**Step 16:** Open Shared page to see files shared by others.
