## Full Run Example – User Flow

![Registration Screen](images/task5_readme/registration_screen.png)  
**Step 1:** Register a new user.

![Login Screen](images/task5_readme/login_screen.png)  
**Step 2:** Log in with the new account.

![Home Page](images/task5_readme/home_page.png)  
**Step 3:** Arrive at Home page.

![Side Menu](images/task5_readme/side_menu.png)  
**Step 4:** Open the side menu and create a new folder called "Project Files".

![My Drive Page](images/task5_readme/my_drive_page.png)  
**Step 5:** Inside "Project Files", create a new file "Report.docx".

![Item Options Menu](images/task5_readme/item_options_menu.png)  
**Step 6:** Rename "Report.docx" to "FinalReport.docx".

![Item Options Menu](images/task5_readme/item_options_menu.png)  
**Step 7:** Star "FinalReport.docx" for quick access.

![Item Options Menu](images/task5_readme/item_options_menu.png)  
**Step 8:** Share "FinalReport.docx" with another user `test@ead.com`.

![Item Options Menu](images/task5_readme/item_options_menu.png)  
**Step 9:** Move "FinalReport.docx" into a subfolder "2026".

![My Drive Page](images/task5_readme/my_drive_page.png)  
**Step 10:** Delete "FinalReport.docx" (moves to Bin).

![Bin Page](images/task5_readme/bin_page.png)  
**Step 11:** Open Bin and restore "FinalReport.docx".

![My Drive Page](images/task5_readme/my_drive_page.png)  
**Step 12:** Delete "FinalReport.docx" permanently.

![Settings Menu](images/task5_readme/settings_menu.png)  
**Step 13:** Open settings, toggle dark mode, and change language.

![Recent Page](images/task5_readme/recent_page.png)  
**Step 14:** Check Recent page to see activity history.

![Starred Page](images/task5_readme/starred_page.png)  
**Step 15:** Check Starred page to verify starred items.

![Shared Page](images/task5_readme/shared_page.png)  
**Step 16:** Open Shared page to see files shared by others.

![System Running](images/task5_readme/system_running.png)  
**Step 17:** End-to-end verification complete — all features exercised successfully.
