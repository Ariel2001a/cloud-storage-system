## Full Run Example – User Flow

![Registration Screen](wiki/task5_readme/register_Screen_run.png)  
**Step 1:** Register a new user.

![Login Screen](wiki/task5_readme/login_run.png)  
**Step 2:** Log in with the newly created account.

![Home Page](wiki/task5_readme/homeafterlogin_run.png)  
**Step 3:** Arrive at the Home page.

![Side Menu](wiki/task5_readme/newfolder_run.png)  
**Step 4:** Open the side menu and create a new folder named **"new folder"**.

![My Drive Page](wiki/task5_readme/newfile_run.png)  
**Step 5:** Enter **"new folder"** and create a new file named **"New file"**.

![Edit File Form](wiki/task5_readme/fileafteredit.png)  
**Step 6:** Edit the content of **"New file"** and save the changes.

![Picture Form](wiki/task5_readme/imageupload.png)  
**Step 7:** Create a new image file inside **"new folder"**.

![Edit Picture Form](wiki/task5_readme/imageafteredit.png)  
**Step 8:** Edit the image by replacing or updating the picture.

![Item Options Menu](wiki/task5_readme/sharedfile.png)  
**Step 9:** Rename **"New file"** to **"new name file"**, star it, and share it with another user.

![Item Options Menu](wiki/task5_readme/sharedfile.png)  
**Step 10:** Log in with a different user account and verify that the shared file appears in the **Shared** page.

![Starred Page](wiki/task5_readme/starredfile.png)  
**Step 11:** Open the **Starred** page to verify the file appears as starred.

![My Drive Page](wiki/task5_readme/fileintrash.png)  
**Step 12:** Delete **"new name file"** (the file is moved to the Bin).

![Bin Page](wiki/task5_readme/filerestore.png)  
**Step 13:** Open the **Bin** and restore **"new name file"**.

![My Drive Page](wiki/task5_readme/filedeleted.png)  
**Step 14:** Delete **"new name file"** permanently.

![Settings Menu](wiki/task5_readme/darkHEBREW.png)  
**Step 15:** Open **Settings**, toggle dark mode, and change the language.

![Recent Page](wiki/task5_readme/recentpage.png)  
**Step 16:** Open the **Recent** page to review the activity history.
